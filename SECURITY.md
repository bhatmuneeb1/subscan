# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public GitHub issue before a fix is available.

Send a concise report to **bhatmuneeb49@gmail.com** with:

- affected version or commit;
- reproduction steps or a minimal proof of concept;
- expected and observed behavior;
- impact assessment;
- suggested remediation, if known.

Please avoid accessing third-party data, causing service disruption, or testing systems without authorization.

I will acknowledge good-faith reports when possible and coordinate remediation and disclosure based on severity and reproducibility.

## Scope

This policy covers vulnerabilities in code maintained in this repository. Vulnerabilities in third-party tools invoked by Subscan should be reported to their respective maintainers.
